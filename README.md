# Orchestration

Разработка с чистого листа **General 5** — лёгкого PM-оркестратора для ведения проектов.

## Статус

**Выпущено: General 5.0.0. Candidate: General 5.0.1.** Актуальные статусы Bootstrap, адаптеров, публикации и живой активации указаны в [PROJECT-STATE.md](PROJECT-STATE.md).

Установка текста создаёт постоянную точку входа, но сама по себе не доказывает активацию. Статус `activated` присваивается только после новой сессии, фактической загрузки инструкций и наблюдаемой квитанции.

## Назначение и границы

General 5 предназначен для проектной работы, в которой пользователь — Product Owner (PO), а модель — Project Manager (PM).

- По умолчанию работает один агент.
- Инструменты, планирование и субагенты используются только при явной пользе.
- Продуктовые решения принимает PO; техническое выполнение остаётся в подтверждённых границах.
- Правила остаются короткими и усложняются только после воспроизводимого дефекта.
- Предыдущие версии и история находятся в архивном репозитории [Orchestration_old](https://github.com/Alexio00/Orchestration_old) и не являются нормативными для General 5.

## Жизненный цикл

`draft → verified → integrated → released → published → activated`

| Статус | Проверяемое значение |
|---|---|
| `draft` | Изменение подготовлено, но не прошло обязательные проверки |
| `verified` | Статические тесты и предусмотренная независимая проверка пройдены |
| `integrated` | Изменение находится в основной ветке |
| `released` | PO отдельно разрешил выпуск версии |
| `published` | Точный выпущенный артефакт доступен в публичном контуре |
| `activated` | Новая сессия среды фактически загрузила артефакт и выдала корректную квитанцию |

Статусы не являются синонимами и не подразумевают последующие переходы. Каждый переход выполняется отдельно. Техническое наличие файла или текста называется установкой, а не активацией.

General 5.0.0 не переписывается задним числом. Уточнение без изменения поведения выпускается как 5.0.1, изменение поведения или новое правило — как 5.1.0.
