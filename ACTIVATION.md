# Активация General 5 в поддерживаемых средах

Статус: основной контур для General 5.0.0. Экспериментальные среды в этот документ не входят.

## Общий контракт

Во всех средах должны быть активированы два слоя:

1. General 5.0.0 — стабильные правила PM.
2. PROJECT-STATE.md — изменяемый снимок конкретного проекта.

AGENTS.md объединяет репозиторный протокол активации и полный дистрибутив General 5.0.0. PROJECT-STATE.md не дублирует генеральный промпт.

После активации модель сообщает:

- версию General;
- репозиторий и ветку;
- свежесть PROJECT-STATE.md;
- текущую цель;
- следующий шаг;
- найденные расхождения.

## Первая поддерживаемая матрица

| Среда | Постоянная точка входа | Состояние | Запуск |
|---|---|---|---|
| ChatGPT Project Chat / Work | Инструкции проекта с текстом GENERAL-5.md | PROJECT-STATE.md в проекте или доступном репозитории | Попросить прочитать состояние и выдать подтверждение активации |
| Codex app / CLI / IDE / cloud | Корневой AGENTS.md | Корневой PROJECT-STATE.md | Открыть корень репозитория и запросить подтверждение активации |
| Claude Project | Project Instructions с текстом GENERAL-5.md | PROJECT-STATE.md в Project Knowledge | Попросить прочитать состояние и выдать подтверждение активации |
| Claude Code local / cloud | Корневой CLAUDE.md импортирует AGENTS.md | Корневой PROJECT-STATE.md | Запустить в корне репозитория и запросить подтверждение активации |
| Qwen Code | Корневой AGENTS.md | Корневой PROJECT-STATE.md | Запустить в корне репозитория и запросить подтверждение активации |
| Обычный чат без проекта | GENERAL-5.md как инструкция или первое вложение | PROJECT-STATE.md вторым вложением | В стартовом сообщении назначить файлы правилами и состоянием |

## Процедуры

### ChatGPT Project Chat / Work

1. Помести дословный текст GENERAL-5.md в инструкции проекта.
2. Добавь PROJECT-STATE.md в знания проекта либо предоставь чату доступ к репозиторию.
3. Стартовый запрос: «Прочитай PROJECT-STATE.md, проверь его свежесть и выдай подтверждение активации».
4. AGENTS.md используется как эталон репозиторного дистрибутива, но не требует дублирования в инструкциях проекта.

### Codex app / CLI / IDE / cloud

1. Открой корень репозитория.
2. Среда читает AGENTS.md как постоянные инструкции.
3. По протоколу AGENTS.md модель читает PROJECT-STATE.md и только затем нужный контекст.
4. Если автоматическое обнаружение не подтверждено, явно запроси: «Прочитай AGENTS.md и PROJECT-STATE.md и выдай подтверждение активации».

### Claude Project

1. Помести дословный текст GENERAL-5.md в Project Instructions.
2. Добавь PROJECT-STATE.md в Project Knowledge.
3. В новом чате запроси проверку состояния и подтверждение активации.
4. Обновляй Project Instructions только при переходе на новую выпущенную версию General.

### Claude Code local / cloud

1. Запусти Claude Code в корне репозитория.
2. CLAUDE.md содержит только импорт AGENTS.md, поэтому правила не дублируются.
3. AGENTS.md направляет модель к PROJECT-STATE.md.
4. Запроси подтверждение активации; при сомнении проверь загруженный контекст средствами самой среды.

### Qwen Code

1. Запусти Qwen Code в корне репозитория.
2. Используй AGENTS.md как постоянную точку входа.
3. AGENTS.md направляет модель к PROJECT-STATE.md.
4. Отдельный QWEN.md в основном контуре не создаётся, пока тест не докажет его необходимость.

### Обычный чат

1. Передай GENERAL-5.md и назови его обязательной инструкцией сессии.
2. Передай PROJECT-STATE.md и назови его текущим состоянием проекта.
3. Попроси сначала выдать подтверждение активации.
4. При смене чата передавай тот же выпущенный General и последний PROJECT-STATE.md.

## Что обновлять

| Событие | GENERAL-5.md | AGENTS.md | CLAUDE.md | PROJECT-STATE.md | Инструкции проектов |
|---|---:|---:|---:|---:|---:|
| Обычное изменение кода или документа | Нет | Нет | Нет | Только если изменился checkpoint | Нет |
| Решение PO, завершение этапа, новый следующий шаг | Нет | Нет | Нет | Да | Нет |
| Новая выпущенная версия General | Новый релиз | Обновить дистрибутив | Обычно нет | Указать новую версию | Обновить один раз |
| Изменение способа активации среды | Нет | При изменении общего протокола | Только если меняется импорт | При необходимости | Только затронутая среда |

Таким образом, при повседневной работе синхронизируется один изменяемый файл — PROJECT-STATE.md. Остальные файлы меняются редко и по отдельным причинам.
