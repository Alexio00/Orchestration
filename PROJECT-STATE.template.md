## Свежесть снимка

Опорная ревизия — последний commit, факты которого учтены в снимке. При активации проверь commits после неё. Сам commit, изменяющий только PROJECT-STATE.md, не считается расхождением. Если более поздние изменения влияют на разделы этого файла, сначала сообщи о расхождении и предложи обновление. Локальный SHA не подтверждает внешние изменяемые факты: перед использованием перепроверь их по указанному источнику.

## Правило обновления

Обновляй файл при значимом checkpoint: изменении цели, границ, решения PO, статуса этапа, открытого вопроса или следующего шага. Не обновляй его ради каждого технического изменения.
